# Dashboard 窗口材质分层规格

> 状态：需求已确认，待实现。2026-09-20 用户多轮口述收敛。
> 本文档只描述「窗口长什么样」，是唯一视觉口径；不涉及任何实现技术选型。
> 实现者有歧义时回到本文档，不要自行发挥。

## 一、整体观感

Dashboard 是一个**整体磨砂半透明的窗口**：透过窗口能看到下方桌面/其他窗口的颜色与明暗变化（柔和的磨砂透光），但**看不清**下方的文字细节。既不是清晰透视，也不是实色不透明。

## 二、三层结构（从下到上，恰好三层）

### 第 1 层：背板

- 铺满**整个窗口**，包括标题栏区域下方和侧栏区域下方。
- 轻微磨砂 + 少量半透明：透得出下方内容的颜色和明暗变化，看不清文字细节。
- 整窗是**一个整体**，不允许按区域割裂成几块不同材质。

### 第 2 层：顶栏渐进模糊

- 位置：窗口顶部一条，覆盖红绿灯、窗口标题「CapsWriter」、右侧外观切换控件所在的整个标题栏高度。
- 它**只是一层模糊效果**，不是色带：顶部区域（红绿灯/标题所在处）始终保持**最强模糊**；只有底部一小条（约 24pt）从完全模糊**快速过渡**到无模糊。过渡要迅速，其余大部分保持最强模糊。
- 内容向上滚动进入该区域时，在模糊层下面被柔化（逐渐糊掉），而不是被生硬的裁剪线切断。
- 不影响上方的红绿灯、窗口标题、外观切换控件——它们始终清晰、不被模糊、不被遮挡。
- **纯模糊**：不允许出现任何白色、灰色或彩色的横条/渐变带。
- 这一层与标题栏是**同一层厚度**：红绿灯、标题、切换控件就在这层里，不允许「标题栏 + 另外一条模糊带」上下堆叠成两条带子。

### 第 3 层：侧栏玻璃

- 左侧导航栏是磨砂玻璃面板，磨砂程度**比背板更轻、更透明**——同一背景下目视对比，侧栏明显比主画布区域更通透。
- 侧栏与主画布交界处过渡自然，无突兀断层。

## 三、明确禁止（观感层面）

1. **禁止全透明**：透到能看清下方窗口文字，内容可读性崩塌。
2. **禁止全不透明**：完全看不出透光。
3. **禁止任何横带/残块**：标题栏、侧栏交界、四角不允许出现实心色带、白色残块或异形色块（浅色、深色模式都包括）。
4. **禁止两条带**：顶栏只有一层厚度，不允许上下堆叠两条。
5. **禁止区域割裂**：背板必须整窗一体，不允许「只填主画布、侧栏另算」这种割裂方案。

## 四、辅助功能

- 系统开启「减少透明度」时，所有层退回不透明实色，可读性优先，布局不变形。

## 五、验收标准（逐项目视，全部通过才算完成）

1. **透光可感知**：窗口压在纯白与纯黑背景上，正文同一区域的观感明显不同；正常桌面下看不清下方文字。
2. **无残块**：浅色、深色各看一遍，标题栏、侧栏交界、四角无任何异形色块/色带。
3. **顶栏单层**：红绿灯、窗口标题、外观切换在同一水平条带内，其下方没有第二条独立的带。
4. **顶栏渐进模糊**：顶栏主体强模糊且稳定；底部约 24pt 快速淡出到无模糊；无任何色带；红绿灯与标题清晰。
5. **滚动柔化**：长页面（如转录历史）向上滚动，内容在顶栏模糊层下缘被柔和地糊掉，滚动全程标题清晰。
6. **侧栏更透**：同一背景下侧栏明显比主画布更通透，交界处无断层。
7. **深浅色**：两种外观各自满足 1–6，切换后立即生效。
8. **减少透明度**：开启后整窗退回实色，布局不变形。
